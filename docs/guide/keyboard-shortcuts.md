# Keyboard shortcuts

| Action                        | macOS                                                   | Windows / Linux                                            |
| ----------------------------- | ------------------------------------------------------- | ---------------------------------------------------------- |
| Command palette               | <kbd>⌘</kbd>+<kbd>K</kbd>                               | <kbd>Ctrl</kbd>+<kbd>K</kbd>                               |
| Command palette (alternative) | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>              | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>              |
| Settings                      | <kbd>⌘</kbd>+<kbd>,</kbd>                               | <kbd>Ctrl</kbd>+<kbd>,</kbd>                               |
| Library                       | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>              | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>              |
| New project                   | <kbd>⌘</kbd>+<kbd>N</kbd>                               | <kbd>Ctrl</kbd>+<kbd>N</kbd>                               |
| Open project                  | <kbd>⌘</kbd>+<kbd>O</kbd>                               | <kbd>Ctrl</kbd>+<kbd>O</kbd>                               |
| Save                          | <kbd>⌘</kbd>+<kbd>S</kbd>                               | <kbd>Ctrl</kbd>+<kbd>S</kbd>                               |
| Save as                       | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>              | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>              |
| Undo                          | <kbd>⌘</kbd>+<kbd>Z</kbd>                               | <kbd>Ctrl</kbd>+<kbd>Z</kbd>                               |
| Redo                          | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>              | <kbd>Ctrl</kbd>+<kbd>Y</kbd>                               |
| Zoom in / out / reset         | <kbd>⌘</kbd>+<kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd> | <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd> |
| Full screen                   | <kbd>Ctrl</kbd>+<kbd>⌘</kbd>+<kbd>F</kbd>               | <kbd>F11</kbd>                                             |
| Close a dialog                | <kbd>Esc</kbd>                                          | <kbd>Esc</kbd>                                             |
| Quit                          | <kbd>⌘</kbd>+<kbd>Q</kbd>                               | <kbd>Ctrl</kbd>+<kbd>Q</kbd> or close the window           |

## Inside the command palette

| Key                         | Action                      |
| --------------------------- | --------------------------- |
| <kbd>↓</kbd> / <kbd>↑</kbd> | Move the highlight          |
| <kbd>Enter</kbd>            | Run the highlighted command |
| <kbd>Esc</kbd>              | Close the palette           |

## In the project tree

| Key                               | Action                                         |
| --------------------------------- | ---------------------------------------------- |
| <kbd>↓</kbd> / <kbd>↑</kbd>       | Select the next / previous item                |
| <kbd>→</kbd> / <kbd>←</kbd>       | Expand / collapse, or go to the child / parent |
| <kbd>Home</kbd> / <kbd>End</kbd>  | First / last item                              |
| <kbd>F2</kbd>                     | Rename the selected document                   |
| <kbd>Delete</kbd>                 | Remove the selected document (asks first)      |
| <kbd>Enter</kbd>                  | Open the selected sheet or board in the viewer |
| <kbd>Enter</kbd> / <kbd>Esc</kbd> | Confirm / cancel renaming                      |

## In the 2D view

Click the drawing area first; see [Viewing sheets and boards](./viewer#navigating).

| Key or gesture                                                        | Action                               |
| --------------------------------------------------------------------- | ------------------------------------ |
| Mouse wheel                                                           | Zoom around the cursor               |
| Two-finger scroll (trackpad)                                          | Pan                                  |
| Pinch (trackpad), <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + wheel                | Zoom continuously                    |
| Middle or right button, <kbd>Space</kbd> + drag                       | Pan                                  |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd>                   | Pan (with <kbd>Shift</kbd>: farther) |
| <kbd>+</kbd> / <kbd>-</kbd>                                           | Zoom in / out                        |
| <kbd>Home</kbd>                                                       | Fit the document to the window       |
| <kbd>F</kbd>                                                          | Zoom to the selection                |
| <kbd>B</kbd>                                                          | View the board from the bottom       |
| Click, <kbd>Shift</kbd> + click, <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + click | Select, add, toggle                  |
| Drag right / left                                                     | Box selection: inside / touching     |
| <kbd>Alt</kbd> + drag                                                 | Lasso selection                      |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>A</kbd>                           | Select every visible object          |
| <kbd>Esc</kbd>                                                        | Clear the selection or cancel a drag |

## In dialogs

| Key                                              | Action                            |
| ------------------------------------------------ | --------------------------------- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between controls             |
| <kbd>Space</kbd>                                 | Toggle a checkbox, press a button |
| <kbd>Esc</kbd>                                   | Close the dialog                  |

## In the schematic editor

Click the drawing area of a sheet first; see
[Drawing schematics](./schematic-editor).

| Key                                                                     | Action                                           |
| ----------------------------------------------------------------------- | ------------------------------------------------ |
| <kbd>A</kbd>                                                            | Add a symbol                                     |
| <kbd>W</kbd>                                                            | Draw a wire                                      |
| <kbd>B</kbd>                                                            | Draw a bus                                       |
| <kbd>L</kbd>                                                            | Place a net label                                |
| <kbd>Shift</kbd>+<kbd>L</kbd>                                           | Place a global label                             |
| <kbd>H</kbd>                                                            | Place a hierarchical label                       |
| <kbd>P</kbd>                                                            | Place a power port                               |
| <kbd>Q</kbd>                                                            | Place a no-connect flag                          |
| <kbd>J</kbd>                                                            | Place a junction                                 |
| <kbd>T</kbd>                                                            | Place a text                                     |
| <kbd>S</kbd>                                                            | Draw a sheet symbol                              |
| <kbd>N</kbd>                                                            | Highlight a net (tool)                           |
| <kbd>`</kbd>                                                            | Highlight the net under the cursor               |
| <kbd>R</kbd> / <kbd>Shift</kbd>+<kbd>R</kbd>                            | Rotate counterclockwise / clockwise              |
| <kbd>Y</kbd> / <kbd>X</kbd>                                             | Mirror left to right / top to bottom             |
| <kbd>G</kbd>                                                            | Drag the selection with its wires                |
| <kbd>M</kbd>                                                            | Move the selection without its wires             |
| <kbd>Delete</kbd>, <kbd>Backspace</kbd>                                 | Delete the selection                             |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | Copy / cut / paste at the cursor                 |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>D</kbd>                               | Duplicate the selection                          |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>F</kbd>                               | Find and replace                                 |
| <kbd>Esc</kbd>                                                          | End the action, then back to **Select and move** |

While drawing a wire:

| Key                            | Action                   |
| ------------------------------ | ------------------------ |
| <kbd>/</kbd>                   | Bend the other way round |
| <kbd>Backspace</kbd>           | Remove the last corner   |
| <kbd>Enter</kbd>, double-click | Finish the wire          |
| <kbd>Esc</kbd>                 | Throw the wire away      |

Layout editor shortcuts will be added here together with the layout editor.
