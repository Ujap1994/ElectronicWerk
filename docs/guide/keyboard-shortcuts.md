# Keyboard shortcuts

| Action                        | macOS                                                   | Windows / Linux                                            |
| ----------------------------- | ------------------------------------------------------- | ---------------------------------------------------------- |
| Command palette               | <kbd>⌘</kbd>+<kbd>K</kbd>                               | <kbd>Ctrl</kbd>+<kbd>K</kbd>                               |
| Command palette (alternative) | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>              | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>              |
| Settings                      | <kbd>⌘</kbd>+<kbd>,</kbd>                               | <kbd>Ctrl</kbd>+<kbd>,</kbd>                               |
| New project (from v0.2)       | <kbd>⌘</kbd>+<kbd>N</kbd>                               | <kbd>Ctrl</kbd>+<kbd>N</kbd>                               |
| Open project (from v0.2)      | <kbd>⌘</kbd>+<kbd>O</kbd>                               | <kbd>Ctrl</kbd>+<kbd>O</kbd>                               |
| Zoom in / out / reset         | <kbd>⌘</kbd>+<kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd> | <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd> |
| Full screen                   | <kbd>Ctrl</kbd>+<kbd>⌘</kbd>+<kbd>F</kbd>               | <kbd>F11</kbd>                                             |
| Close a dialog                | <kbd>Esc</kbd>                                          | <kbd>Esc</kbd>                                             |
| Quit                          | <kbd>⌘</kbd>+<kbd>Q</kbd>                               | <kbd>Ctrl</kbd>+<kbd>Q</kbd> or close the window           |

## Inside the command palette

| Key                         | Action                      |
| --------------------------- | --------------------------- |
| <kbd>↓</kbd> / <kbd>↑</kbd> | Move the highlight          |
| <kbd>Enter</kbd>            | Run the highlighted command |
| <kbd>Esc</kbd>              | Close the palette           |

## In dialogs

| Key                                              | Action                            |
| ------------------------------------------------ | --------------------------------- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between controls             |
| <kbd>Space</kbd>                                 | Toggle a checkbox, press a button |
| <kbd>Esc</kbd>                                   | Close the dialog                  |

Editor shortcuts (placing parts, routing, …) will be added here together with
the editors.
